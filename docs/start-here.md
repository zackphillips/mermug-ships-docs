# Start Here

This is Mermug's ship's documentation: emergency procedures, how the boat's
systems are built, service intervals and the maintenance log. Every page is a
Markdown file in [`zackphillips/mermug-ships-docs`](https://github.com/zackphillips/mermug-ships-docs),
and once loaded the whole set stays readable offline.

Add this site to your phone's home screen before you need it offshore.

## Sections

| Section | What is in it |
|---|---|
| Operations | Procedures: man overboard, reefing, anchoring, engine start |
| Systems | How the boat is built: electrical, plumbing, rig, electronics |
| Maintenance | Service intervals, spares, [the maintenance log](maintenance/log.md) |
| Voyages | Passage notes |

## Checklists

Items shown as boxes can be ticked. Ticks are stored on this device only and
are cleared with **Reset** at the top of the page.

## Adding or fixing a page

- **From a phone:** open the repository, go to `docs/`, **Add file → Create
  new file**, name it for the subject (`operations/reefing.md`), write it,
  commit. It is live about a minute later.
- **With Claude:** open the repository in Claude Code and describe what you
  want, e.g. "draft a reefing procedure from these notes" or "log an impeller
  change at 1204 hours". `CLAUDE.md` carries the conventions.
- **Any page:** use **Edit on GitHub** at the top.
